# Integrated Circuits

## Types of Digital IC
* Microcontroller
	* A.K.A. CPU
* Logic Gates
	* Ex: TTL
* Memory chips
	* RAM, ROM

## Digital IC:
* Collection of:
	* resistor
	* diode
	* transistor
* Placed at piece of semiconductor
	* chip

## Digital IC Types
| Complexity | Gates               |
| :--------- | ------------------- |
| SSI        | < 10                |
| MSI        | 10 - 99             |
| LSI        | 100 - 9,999         |
| VLSI       | 10,000 - 99,999<br> |
| ULSI       | 100,000 - 999,999   |
| GSI        | > 1,000,000         |
